Шаг 2 · Выбор бэкенда

Через что прокси будет ходить за моделью.
CLI должен быть установлен и залогинен. Авторизация требует TTY — выполни в SSH: claude login / codex login / gemini auth.
Переменные исторически называются KIMI_*, по факту это любой OpenAI-совместимый endpoint (OpenAI, OpenRouter, DeepSeek, Mistral, Cerebras, xAI, Anthropic…).
